Session

The snapshot is the single source of truth for the YouTube login session: the periodic refresh pipeline renews it, and yt-dlp always receives a one-time copy of it, never the original.

Snapshot status

Periodic health check

Every 12 hours (by default) a one-time snapshot copy is probed to answer "is the session still usable?". An unhealthy result triggers a throttled automatic refresh; consecutive failures raise an alert. It runs automatically once a snapshot exists.

PO token provider

Generates YouTube PO tokens through the bgutil script, executed by Deno whenever yt-dlp needs one (no server process). Needed for videos that play in the browser but are denied to API clients from flagged IPs. The pieces install automatically at startup.

Import session

Log in to youtube.com in a real browser, export the cookies of the youtube.com domain (Netscape file or browser JSON export), close that browser completely, then paste them here. The import only replaces the snapshot when the InnerTube probe accepts it.
