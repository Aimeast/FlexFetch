YouTube session

The snapshot is the single source of truth for the YouTube login session: the periodic refresh pipeline renews it, and yt-dlp always receives a one-time copy of it, never the original.

Snapshot status

Periodic health check

Every 12 hours (by default) the session is checked. While the snapshot is young a one-time copy is probed; an aged snapshot runs the full refresh pipeline instead - its probe is the same authoritative check, and the verdict lands here either way. An unhealthy light check triggers a throttled automatic refresh; consecutive failures raise an alert. It runs automatically once a snapshot exists.

YouTube PO token provider

Generates YouTube PO tokens through the bgutil script, executed by Deno whenever yt-dlp needs one (no server process). Needed for videos that play in the browser but are denied to API clients from flagged IPs. The pieces install automatically at startup.

Import YouTube session

Log in to youtube.com in a real browser, export the cookies of the youtube.com domain (Netscape file or browser JSON export), close that browser completely, then paste them here. The import only replaces the snapshot when the InnerTube probe accepts it.

X session

An imported auth_token unlocks posts that X gates for anonymous visitors (sensitive media, age-restricted content). The token is stored encrypted; downloads still fetch the media from the CDN without it. Nothing here refreshes on its own - verify manually after logging out of that X session elsewhere.

Import X session

Log in to x.com in a real browser, export the cookies of the x.com domain (Netscape file or browser JSON export), then paste them here. The auth_token cookie is required; the import is only accepted when x.com confirms the token is live.
